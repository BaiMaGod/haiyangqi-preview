游戏规则

  1. 首翻定阵营：你第一次翻出的棋子属于哪一方，你就控制哪一方。
  2. 每回合只做一件事：翻一张暗牌，或让己方棋子上下左右移动一格，或吃掉相邻敌子。
  3. 大吃小：8级虎鲸一路压到1级藤壶；同等级可以互吃。
  4. 唯一例外：1级藤壶可以吃8级虎鲸，而虎鲸不能吃藤壶。
  5. 排位：赢棋 +1 胜点、输棋 -1 胜点；根据当前段位匹配同段位对手。
  6. 晋级保护：晋级后的两场对局不会掉回上一段。
  7. 重开：确定阵营后中途重新开局，会按本局失败结算 -1 胜点。
  8. 获胜：消灭对方全部棋子。

暗牌翻开前，双方都无法得知它的阵营和等级。

肉鸽模式

每次主动吃子有20%概率触发三选一；奇遇连连提高至30%。每方最多获得3项，本局有效。技能在“奇遇”中使用，选择期间暂停行动。

献祭标记公开显示。“以小博大”被同级或相差1级敌棋吃掉时，双方死亡；反伤不会再次触发奇遇。双方最后棋子同归于尽为和棋。

肉鸽战绩单独记录，不影响普通段位胜点。
